# 基於寫字及視覺動作整合訓練提升發展協調障礙學童書寫學習成效之應用程式
 
📖 專案簡介
發展協調障礙（Developmental Coordination Disorder, DCD）的學童常因精細運動動作與視知覺整合困難，在書寫時面臨速度調節失衡、筆壓控制不佳及停頓頻繁等困境。由於此類動作障礙無法隨年齡自然痊癒，早期介入訓練刻不容緩。
PathFinder 旨在掌握黃金治療期，專為 DCD 學童開發一款結合遊戲化設計的數位學習應用程式。本系統融合「任務導向學習（CO-OP）」與「漸進式學習」理論，透過 iPad Pro 與 Apple Pencil 的高精準度硬體支援，協助治療師與家長引導學童進行書寫訓練、視知覺訓練與手部精細動作訓練。

--------------------------------------------------------------------------------
✨ 核心功能模組
1. 書寫訓練 (Handwriting Training)
針對學童寫字速度慢、筆壓控制不佳與頻繁停頓的核心痛點，結合漸進式學習法與認知導向日常職能表現（CO-OP）策略：

    漸進式基礎運筆： 學習內容依循中文字的三層階層式正字結構，從職能治療推薦的「九大核心基礎運筆元素」（｜、－、○、＋、／、□、＼、╳、△）開始，過渡至筆劃組合，最終進階至國家教育研究院公布之七階漢字分級標準的真實中文字。
    視覺鷹架抽離： 提供從顯示筆劃仿寫，漸進抽離至僅提供範例讓使用者觀察後自行默寫的挑戰，以降低學童對外部協助的依賴。
    動態即時視覺回饋： 採用動態壓力回饋機制，即時解析觸控筆壓改變筆畫顏色（🟢 綠色表適中、🔵 藍色表過輕、🔴 紅色表過重），引導學童在動作執行當下進行自我對話與力道修正，促進大腦前饋處理過程，建立穩定的肌肉張力。

2. 視覺動作整合 - 視知覺訓練 (Visual Perception Training)
依據「中文字視知覺測驗 (CCVPT)」的三大核心向度設計遊戲化關卡，精準針對中文字書寫的視知覺需求進行訓練：

    🐙 視覺辨識（章魚變色龍-筆劃捉迷藏）： 透過比對選項中的幾何圖形、筆劃與文字部件，訓練專注細節差異與視覺辨識能力。
    🐠 視覺空間知覺（深海發光魚-寬度探測器）： 觀察物件的間距、寬度與相對位置，逐步建立空間關係與比例判斷能力。
    🚢 視覺記憶（沉船藏寶圖-筆劃重組）： 在短時間內記憶圖形或文字結構，並從干擾選項中準確回想重組，強化短期圖像記憶。

3. 視覺動作整合 - 手部影片訓練 (In-Hand Manipulation Training)
彌補數位載具缺乏真實物品觸感與形體特性之限制，結合生活情境提供手內操作 (In-Hand Manipulation, IHM) 技巧訓練：

    利用硬幣的拿取、握筆時的調整及旋轉瓶蓋等日常物品，系統性拆解示範動作。
    訓練涵蓋三大面向：指尖至掌心轉移、手部移動、以及手部旋轉，並依據學習狀況提供難易度選擇。

🛠 技術架構與學習成效分析
硬體與框架

    Device: 具備 ProMotion 技術之 iPad Pro。
    Input: Apple Pencil。
    Frameworks:
        整合 UITouch 物件即時監測觸碰位置與壓力屬性 (force 與 maximumPossibleForce)。
        結合 PencilKit 框架，解析 PKStrokePath 內建的 timeOffset 屬性，精確計算筆劃位移、時間差與動態速度軌跡。

自動化進階與評估演算法
為協助治療師量化追蹤學童的動作控制能力，系統建構了動態自動化進階演算法，統整以下三大指標：

    自動化評估 (NCV)： 計算每筆劃中速度方向改變次數 (Number of changes of velocity direction per stroke)。系統將連續練習的 NCV 數值繪製為「乙狀曲線」，當 NCV 減少超過 50% 且趨於穩定時形成的轉折點，即代表學童達成寫字自動化所需的練習字數。
    平均筆劃速度分數： 針對學童書寫簡單字過快及複雜字過慢的特性，採用高斯區間評分，透過係數設定錯誤可容忍度範圍。
    平均寫字壓力分數： 針對學童難以建立預期性動作計畫之特性，採用變異係數歸一化評分。書寫壓力越穩定，變異比值越低，分數越高。
